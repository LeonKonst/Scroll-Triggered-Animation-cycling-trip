# Scroll-Triggered Animation: Cycling Trip to Møns Klint

This project demonstrates a scroll-triggered animation using a sequence of cycling trip frames displayed on a canvas at the top of the page. As you scroll, the animation advances through the frames, creating a smooth visual storytelling effect.

## Features

- Scroll-driven frame-by-frame animation using HTML5 Canvas
- Responsive design with a fixed header and smooth scrolling
- A genuine experience cycling from Copenhagen to Møns Klint in 2 days

## Usage

Open `index.html` in your browser to see the scroll-triggered animation in action.

## Structure

- `index.html` – Main page with canvas and trip story
- `script.js` – Handles image preloading and scroll animation logic
- `frames/` – Contains animation frame images
- `styles.css` – Styling for layout and animation
